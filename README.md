# Ohm-s_Law-Calculator-JNC-calculator-
The JNC Calculator: a terminal-based Ohm’s Law calculator in C++ with 12 formula variants for V, I, R, and P, a reusable calculation history, and divide-by-zero guards. Built with ANSI escape codes, a spiral loading animation, termios non-blocking input, and a scrolling credits roll. Linux/macOS.
